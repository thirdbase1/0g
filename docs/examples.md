# S³ Examples

S³ includes several examples located in `/examples`:
- **Hello World**: A simple "Hello S³" app to learn basic configuration.
- **Basic Auth**: Shows entities, routing, checking user credentials, hashing, and sessions.
- **Wallet Starter**: Contains complex data flows, checks, balances, and real logic primitives.
- **Vercel Demo**: An app intended to be deployed directly to Vercel.
