# Philosophy

Speed, Simplicity, and Security are not just features; they are foundational to the S⁴ language.

We wanted an abstraction layer that reads as cleanly as HTML but provides a full-stack, secure server infrastructure.

- **Speed:** Bun-first compiler outputs highly efficient JavaScript code. No massive virtual-DOM, no heavy middleware.
- **Simplicity:** No semicolons, no brackets. Pure, indentation-based semantic definitions.
- **Security:** CSRF, password hashing, XSS escaping, and rate-limiting are built-in features, automatically wired by the compiler to keep you safe by default.
