# Philosophy

1. **Speed**: Run fast, compile fast. S³ natively runs on Bun and Node. Code is transpiled to minimal, highly-optimized runtime code.
2. **Simplicity**: No curly brace soup. Indentation defines the logic. Human-readable keywords over symbols. A single, obvious way to do things.
3. **Security**: Safe by default. Escaped output, rate-limiting, explicit role guards, and CSRF protection are built-in and enabled by default. You have to opt out of security, not opt in.

We want building secure apps to be as easy as writing simple markup.
