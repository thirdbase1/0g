# S³ Roadmap

### v1 Core Release
- Initial `.s3` Syntax Parsing.
- Monorepo tooling (`@s3/cli`, `@s3/compiler`).
- `bun` backend runtime logic.
- Node and Vercel Adapters built out.
- Core Primitives: `app`, `page`, `route`, `flow`, `entity`.

### v2 Future Features
- Hot Module Replacement (HMR).
- Extensible Database adapters.
- WebSocket / Server-sent Events primitive.
