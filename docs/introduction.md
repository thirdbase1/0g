# Introduction to S³

S³ is a custom web framework designed for Speed, Simplicity, and Security.

It introduces the `.s3` language, an indentation-based DSL that resembles a cleaner, simplified markup rather than verbose JS. The core goal is to generate extremely fast server code optimized for Node.js and Vercel while keeping the developer experience approachable for beginners.

With S³, you just describe your data flows, and the compiler handles security, validation, and optimizations.
