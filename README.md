# PulseStack

**Fast products, not just fast routes.**

PulseStack is a product-first framework designed for vibecoders and fast builders who want to create real digital products quickly: fintech apps, VTU platforms, wallet dashboards, admin panels, Telegram-integrated apps, webhook-heavy systems, internal tools, and polished landing pages.

## Why PulseStack?

1. **Product-First Starter:** Instead of an empty project, you get a real product shell with auth, dashboards, tables, and settings.
2. **Mature UI:** Premium, modern, and production-ready components.
3. **Flow-Based Backend:** Treat business logic as flows (create user, credit wallet) that are structured, readable, and type-safe.
4. **Built-in Webhook Engine:** First-class support for receiving, verifying, and retrying webhooks.
5. **Ledger-Safe Transactions:** A money-flow module built for fintech products.
6. **Blazing Fast:** Built on Bun. Fast startups, fast hot-reloads, fast routes.

## Quick Start

```bash
bun install
bun run --cwd packages/cli dev
```

Check the `docs/` folder for more details on architecture, commands, and roadmap.
